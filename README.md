# FatCat

FatCat is a visual, screen-aware native macOS interface for Hermes. It gives
Hermes a face, eyes on the screen, and presence. Chat is a polished Hermes ACP
session; the avatar follows Hermes’s real state. FatCat is not a second
intelligence, IDE, or browser agent.

Voice is part of the product definition and is not in this build yet.

## Hermes and providers

FatCat ships a pinned Hermes source snapshot and a bundled Python runtime inside
the app. The first-run Settings screen exposes the initial Hermes provider
slice:

- OpenAI Codex: Hermes detects the official Codex auth state, including an
  existing Codex subscription login.
- OpenAI-compatible API: enter an API key and, optionally, an HTTP(S) `/v1`
  base URL for OpenAI or a compatible server.
- Anthropic / Claude API: enter an Anthropic API key.

API keys are stored in the macOS Keychain. FatCat sends Hermes only an opaque
Keychain reference over its private socket; the key is injected into the
bundled agent process at launch and is never written to Hermes config or logs.
The default provider and model are always selected explicitly in Settings;
FatCat does not silently fail over to another provider.

Hermes is vendored from the upstream MIT-licensed project. See
`vendor/hermes/LICENSE` and `vendor/hermes/FATCAT_HERMES_COMMIT` for attribution
and provenance.

## Run

```bash
npm install
./scripts/run-peppa-macos.sh
```

Text conversations persist locally and resume their Hermes ACP session after a
relaunch. A working Hermes provider is required for real responses.

## Verify

```bash
swift build --package-path macos/PeppaAnywhere
swift test --package-path macos/PeppaAnywhere
PYTHONPATH=agent python3 -m unittest discover -s agent/tests
bash scripts/test-hermes-bundle.sh
```

## Build a distributable DMG

The build machine needs the pinned Hermes Python runtime/dependencies available
under `~/.hermes/hermes-agent` (or `PEPPA_HERMES_BUILD_SOURCE`). The resulting
`FatCat.app` and `dist/FatCat.dmg` contain the runtime and do not require Hermes
to be installed on the user’s Mac.

```bash
./scripts/run-peppa-macos.sh
```

The release gate verifies the embedded commit, license, runtime startup, and
that auth files, environment files, generated bytecode, and developer paths
are absent from the staged agent.
